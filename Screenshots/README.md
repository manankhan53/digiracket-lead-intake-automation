## Safe capture notes

- Use a test-only record, never a real prospect's data.
- Keep the Make module names and the Airtable/email flow visible, but never include the actual webhook URL or API key.
- Redaction must be opaque (cover sensitive text completely); a light blur can still be readable after download.
- The Make scenario and Airtable base retain their original labels from before the DigiRacket rebrand.
